GitHub Group Project Guide

Feature Branch Workflow

From creating a branch to merging it into main — explained in English and Sinhala.

Golden Rule: Do not normally develop directly on main. Create a feature branch and work there.
මූලික නීතිය: සාමාන්‍යයෙන් main branch එකේ direct code කරන්න එපා. Feature branch එකක් හදාගෙන ඒකේ වැඩ කරන්න.

1Go to Main Branch / Main Branch එකට යන්න

git checkout main
English:
This switches your local project to the main branch.
සිංහල:
මෙයින් ඔයාගේ local project එක main branch එකට මාරු වෙනවා.

2Get Latest Main / Latest Main එක ගන්න

git pull origin main
English:
Downloads the latest changes from the GitHub main branch.
සිංහල:
GitHub එකේ main branch එකේ තියෙන latest changes ඔයාගේ PC එකට ගන්නවා.

3Create a Feature Branch / Feature Branch එකක් හදන්න

git checkout -b feature-login
English:
Creates a new branch called feature-login and switches to it immediately.
සිංහල:
feature-login නමින් අලුත් branch එකක් හදලා එකවරම ඒ branch එකට මාරු වෙනවා.

Other examples / වෙනත් උදාහරණ

git checkout -b feature-dashboard
git checkout -b feature-user-management
git checkout -b feature-reports
git checkout -b feature-database

4Check Current Branch / දැන් ඉන්න Branch එක බලන්න

git branch

Example output:

main
* feature-login
English:
The branch with the * is your current branch.
සිංහල:
* ලකුණ තියෙන branch එක තමයි දැන් ඔයා වැඩ කරන branch එක.

5Do Your Coding / Code කරන්න

English:
Now edit files and build only the feature related to this branch. Example: login page, validation, authentication UI.
සිංහල:
දැන් මේ branch එකට අදාල feature එක code කරන්න. උදාහරණයක් ලෙස Login page, validation, authentication UI වගේ දේවල්.

6Check Changed Files / වෙනස් වුණු Files බලන්න

git status
English:
Shows modified, new, deleted and staged files.
සිංහල:
වෙනස් කළ files, අලුත් files, delete කළ files සහ staged files පෙන්වනවා.

7Add Files to Staging / Files Stage කරන්න

git add .
English:
Adds all current changes to the staging area, ready for commit.
සිංහල:
දැනට තියෙන changes සියල්ල commit එකට සූදානම් කරන staging area එකට දානවා.

8Create a Commit / Commit එකක් හදන්න

git commit -m "Add login feature"
English:
Creates a saved checkpoint of your changes with a clear message.
සිංහල:
ඔයාගේ changes වල saved checkpoint එකක් message එකක් එක්ක හදනවා.

Good commit examples

git commit -m "Add login page UI"
git commit -m "Add login validation"
git commit -m "Fix login button issue"

9Push Feature Branch / Feature Branch එක GitHub එකට Push කරන්න

git push -u origin feature-login
English:
Uploads your local feature-login branch to GitHub. The -u links your local branch to the remote branch.
සිංහල:
ඔයාගේ local feature-login branch එක GitHub එකට upload කරනවා. -u එකෙන් local branch එක remote branch එකට link කරනවා.
After the first push, you can usually use only: 
git push
පළමු push එකෙන් පස්සේ සාමාන්‍යයෙන් git push විතරක් භාවිතා කරන්න පුළුවන්.

10Create Pull Request / Pull Request එකක් හදන්න

feature-login  →  main
English:
Open GitHub → Pull Requests → New Pull Request. Set base: main and compare: feature-login.
සිංහල:
GitHub → Pull Requests → New Pull Request යන්න. base: main සහ compare: feature-login දාන්න.

11Review and Merge / Review කර Merge කරන්න

English:
Another team member checks the code. If everything is correct, merge the Pull Request into main.
සිංහල:
වෙන team member කෙනෙක් code එක check කරනවා. හරි නම් Pull Request එක main branch එකට merge කරනවා.

12Update Local Main After Merge / Merge එකෙන් පස්සේ Local Main Update කරන්න

git checkout main
git pull origin main
English:
Switches back to main and downloads the newly merged changes.
සිංහල:
ආපහු main branch එකට ගිහින් merge වුණු latest code එක PC එකට ගන්නවා.

13Create the Next Feature Branch / ඊළඟ Feature Branch එක හදන්න

git checkout -b feature-dashboard
English:
Create the next feature branch from the latest main.
සිංහල:
Latest main එකෙන් ඊළඟ feature එකට අලුත් branch එකක් හදන්න.

Daily Workflow / දිනපතා වැඩ කරන Flow එක

git checkout main
git pull origin main
git checkout feature-login

# Do coding

git status
git add .
git commit -m "Update login feature"
git push
Main → Pull Latest → Feature Branch → Code → Status → Add → Commit → Push → Pull Request → Review → Merge

4-Member Example / Members 4 දෙනෙකුගේ Example එක

main
│
├── feature-login            → Member 1
├── feature-dashboard        → Member 2
├── feature-user-management  → Member 3
└── feature-reports          → Member 4
Each member can work on a different feature branch. After completing the feature, create a Pull Request and merge it into main.

එක් එක් member තමන්ගේ feature branch එකේ වැඩ කරන්න. Feature එක complete වුණාම Pull Request එකක් හදලා main එකට merge කරන්න.

Important Rules / වැදගත් නීති

Do not upload / Upload කරන්න එපා:
Passwords, API keys, .env files, secret tokens, database passwords.
Do not code directly on main.
Main branch එකේ direct code කරන්න එපා.
